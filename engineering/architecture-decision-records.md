# Architecture Decision Records

## Purpose

ADR workflow for engineering decisions.

## ADR Process

1. **Propose**: Create ADR for significant decisions.
2. **Review**: Discuss in PR with engineering team.
3. **Decide**: Consensus-based decision.
4. **Implement**: Implement the decision.

## ADR Template

```markdown
# [Number]. [Title]

- **Status**: [Proposed | Accepted | Deprecated]
- **Date**: [YYYY-MM-DD]

## Context

[Problem statement]

## Decision Drivers

[Key requirements]

## Options

[Considered options]

## Decision

[Chosen option and rationale]

## Consequences

[Pros and cons]
```
