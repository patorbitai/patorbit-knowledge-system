# Resume Generation

## Purpose

This document defines the AI-powered resume generation capabilities.

## Capabilities

- Professional summary generation based on claims.
- Experience description enhancement.
- Skills extraction and formatting.
- ATS optimization.

## Workflow

1. Retrieve user claims, skills, and evidence from the Knowledge Graph.
2. Select relevant claims for the target role.
3. Generate optimized descriptions.
4. Validate output against ATS guidelines.
