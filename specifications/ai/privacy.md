# Privacy

## Purpose

AI-specific privacy controls.

## Controls

| Control               | Implementation                                     |
| --------------------- | -------------------------------------------------- |
| **PII Masking**       | Detect and mask PII before sending to providers.   |
| **Zero Retention**    | Configure providers for zero data retention.       |
| **No Training**       | Ensure user data is never used for model training. |
| **Data Minimization** | Send only necessary data to providers.             |
| **Consent**           | Obtain user consent before AI processing.          |
