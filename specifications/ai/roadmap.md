# Roadmap

## Purpose

Long-term AI platform evolution strategy.

## Phases

### Phase 1: Foundation (Current)

- [x] Provider abstraction layer
- [x] Semantic caching
- [x] Basic RAG pipeline
- [x] Resume generation prompts
- [x] Evaluation pipeline

### Phase 2: Capabilities (Next)

- [ ] Specialized AI agents (Career Coach, Recruiter Assistant)
- [ ] Multi-modal document understanding
- [ ] Agentic workflows (multi-step orchestration)
- [ ] Advanced RAG with Knowledge Graph integration
- [ ] A/B testing infrastructure

### Phase 3: Intelligence (Mid-term)

- [ ] Adaptive prompting (personalize prompts per user)
- [ ] Reinforcement learning from human feedback (RLHF)
- [ ] Continuous model evaluation and automatic switching
- [ ] AI-powered anomaly detection for verification
- [ ] Real-time career coaching chat

### Phase 4: Autonomy (Long-term)

- [ ] Autonomous Knowledge Graph curation
- [ ] Predictive career modeling
- [ ] AI-powered recruiter matching
- [ ] Cross-platform data integration
- [ ] Custom model fine-tuning

## Research Initiatives

- Fine-tuning smaller models for specific tasks (skill extraction, classification).
- On-device AI for privacy-sensitive operations.
- Graph neural networks for career path prediction.
