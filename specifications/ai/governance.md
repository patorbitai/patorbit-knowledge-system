# Governance

## Purpose

AI governance, compliance, and documentation standards.

## Governance Model

| Role            | Responsibility                              |
| --------------- | ------------------------------------------- |
| AI Team Lead    | Prompt quality, model selection, evaluation |
| Product Manager | Feature alignment, user impact              |
| Security Team   | Safety, privacy, compliance                 |
| Legal           | Regulatory compliance, terms of use         |

## Approval Process

| Change Type           | Required Approvals                |
| --------------------- | --------------------------------- |
| New prompt template   | AI Team Lead + Product Manager    |
| Prompt version change | AI Team Lead                      |
| New model provider    | AI Team Lead + Security           |
| New AI feature        | AI Team Lead + Product + Security |
| Guardrail change      | AI Team Lead + Security           |

## Documentation Standards

- All prompts are documented with purpose, version, and expected behavior.
- Evaluation results are stored for each prompt version.
- Incident reports are documented for AI-related issues.
