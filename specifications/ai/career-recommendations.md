# Career Recommendations

## Purpose

AI-powered career path and skill development recommendations.

## Capabilities

- **Career Path Prediction**: Suggest career paths based on current skills and experience.
- **Skill Gap Analysis**: Identify missing skills for target roles.
- **Learning Recommendations**: Suggest courses, certifications, and resources.
- **Market Insights**: Provide salary ranges, demand data, and industry trends.

## Recommendation Sources

- User's current claims and verified skills.
- Knowledge Graph (skills, roles, organizations).
- Market data (industry trends, salary benchmarks).
- Similar user profiles (anonymized).
