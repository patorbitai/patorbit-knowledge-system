# Illustrations

## Purpose

Guidelines for illustration usage across the Patorbit platform.

## Style

- **Style**: Flat vector, rounded shapes, limited palette.
- **Colors**: Brand primary + neutral grays.
- **Use cases**: Empty states, onboarding, marketing.
- **Responsiveness**: SVGs scale to container width.

## Accessibility

- Decorative illustrations use `aria-hidden="true"`.
- Informational illustrations include alt text.
