# Spacing

## Purpose

This document defines the spacing scale and layout grid for the Patorbit design system, ensuring consistent spacing across all interfaces.

## Spacing Scale

Based on a 4px base unit:

| Token          | Value | Usage            |
| -------------- | ----- | ---------------- |
| `--space-0`    | 0px   | None             |
| `--space-0\.5` | 2px   | Tight inset      |
| `--space-1`    | 4px   | Icon gaps        |
| `--space-2`    | 8px   | Button gaps      |
| `--space-3`    | 12px  | Input padding    |
| `--space-4`    | 16px  | Card padding     |
| `--space-5`    | 20px  | Section gap      |
| `--space-6`    | 24px  | Heading margin   |
| `--space-8`    | 32px  | Section margin   |
| `--space-10`   | 40px  | Page section     |
| `--space-12`   | 48px  | Page padding     |
| `--space-16`   | 64px  | Large separation |

## Layout Grid

- **Max Content Width**: 1280px
- **Grid Columns**: 12-column grid
- **Gutter**: 24px (desktop), 16px (tablet), 8px (mobile)
