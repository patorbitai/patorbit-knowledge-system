# Icons

## Purpose

This document defines icon usage guidelines for the Patorbit design system.

## Icon Set

- **Library**: Lucide Icons (open-source, consistent design).
- **Size**: 16px (inline), 20px (buttons), 24px (navigation).
- **Style**: Outline, 1.5px stroke weight, rounded caps.
- **Color**: Inherits text color via `currentColor`.

## Usage Rules

- Icons are decorative by default; use `aria-hidden="true"`.
- Standalone icons (no visible label) require `aria-label`.
- Icons align to the baseline of adjacent text.
