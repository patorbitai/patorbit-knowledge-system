# Animations

## Motion System

- **Library**: CSS transitions + Framer Motion for complex animations.
- **Respect Motion**: `prefers-reduced-motion` disables non-essential animations.

## Categories

| Type               | Duration | Examples                       |
| ------------------ | -------- | ------------------------------ |
| Micro-interactions | 100ms    | Button hover, focus ring       |
| Transitions        | 200ms    | Drawer open, modal fade        |
| Page transitions   | 300ms    | Route change                   |
| Attention          | 500ms    | Toast slide-in, skeleton pulse |

## Loading States

- Skeleton screens for page and section loading.
- Spinner for inline button/action loading.
- Progress bar for multi-step operations (uploads, AI processing).
