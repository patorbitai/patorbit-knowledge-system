# Monetization

## Purpose

Revenue streams for the platform.

## Revenue Streams

| Stream              | Source                            | Priority  |
| ------------------- | --------------------------------- | --------- |
| Subscriptions       | Individual and organization plans | Primary   |
| Verification Fees   | Per-claim verification            | Secondary |
| AI Credits          | Premium AI usage                  | Secondary |
| Enterprise Licenses | Custom enterprise deals           | Growth    |
| API Usage           | API-based billing                 | Future    |
| Marketplace Fees    | Transaction fees                  | Future    |

## Revenue Model

- **Primary**: Recurring subscription revenue (MRR/ARR).
- **Secondary**: Usage-based fees (usage scales with adoption).
- **Future**: Transaction-based revenue (marketplace).
