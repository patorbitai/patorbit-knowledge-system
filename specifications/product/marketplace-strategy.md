# Marketplace Strategy

## Purpose

Talent marketplace strategy.

## Marketplace Model

- **Two-sided**: Professionals and recruiters/organizations.
- **Quality Signal**: Verified claims as trust signal.
- **Revenue**: Transaction fees on successful matches.

## Phases

| Phase       | Description                                       |
| ----------- | ------------------------------------------------- |
| **Phase 1** | Passive job board — candidates searchable         |
| **Phase 2** | Active matching — AI-powered recommendations      |
| **Phase 3** | Transactions — apply, interview, hire on platform |
