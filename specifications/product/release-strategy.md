# Release Strategy

## Purpose

Product release cadence and management.

## Release Cadence

- **Major**: Quarterly (themed releases).
- **Minor**: Bi-weekly (features).
- **Patch**: As needed (bug fixes).

## Release Process

1. **Planning**: Prioritize features for release.
2. **Development**: Feature work with QA.
3. **Testing**: QA, staging, smoke tests.
4. **Staging**: Final validation.
5. **Production**: Canary rollout.
6. **Monitoring**: Post-release monitoring.
7. **Retrospective**: Lessons learned.
