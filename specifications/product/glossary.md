# Glossary

## Purpose

Business glossary of key product terms.

| Term             | Definition                                      |
| ---------------- | ----------------------------------------------- |
| Career Passport  | Aggregated, verified career record              |
| Claim            | Single professional achievement statement       |
| Evidence         | Supporting proof for a claim                    |
| Verification     | Confirmation of evidence authenticity           |
| Trust Score      | Reliability metric derived from verification    |
| Confidence Score | Certainty metric combining trust and AI signals |
| Knowledge Graph  | Connected network of career entities            |
| Workspace        | Organizational collaboration environment        |
| Recruiter        | Talent professional using the platform          |
| Issuer           | Entity authorized to issue credentials          |
