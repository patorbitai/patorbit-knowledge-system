# Experimentation

## Purpose

A/B testing and product experimentation framework.

## Process

1. **Hypothesis**: Define a testable hypothesis.
2. **Design**: Minimum detectable effect, sample size.
3. **Implement**: Create feature flag variant.
4. **Run**: Randomize users, run for statistical significance.
5. **Analyze**: Compare metrics, determine winner.
6. **Act**: Roll out winning variant, document learnings.

## Experiment Types

| Type          | Duration  | Complexity |
| ------------- | --------- | ---------- |
| UI Tests      | 1-2 weeks | Low        |
| Pricing Tests | 4-8 weeks | Medium     |
| Feature Tests | 2-4 weeks | High       |
