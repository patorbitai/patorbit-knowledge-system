# Jobs to Be Done

## Purpose

Customer needs analysis using Jobs-to-Be-Done framework.

## Core Jobs

| Job                       | Actor              | Context          | Outcome                     |
| ------------------------- | ------------------ | ---------------- | --------------------------- |
| Maintain career record    | Professional       | Career changes   | Always up-to-date passport  |
| Verify a claim            | Professional       | Job application  | Trusted proof of experience |
| Find qualified candidates | Recruiter          | Hiring           | Reduced screening time      |
| Verify employee history   | Organization Admin | Background check | Confirmed employment        |
| Generate a resume         | Professional       | Job application  | Tailored, optimized resume  |

## Emotional Jobs

- **Confidence**: Feeling confident that career data is accurate and verifiable.
- **Trust**: Knowing that claims are backed by evidence.
- **Control**: Having control over who sees what career data.
