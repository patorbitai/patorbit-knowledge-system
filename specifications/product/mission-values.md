# Mission & Values

## Mission

To empower every professional with a trusted, verifiable, and intelligent career identity that opens doors to opportunities worldwide.

## Core Values

| Value              | Description                                                   |
| ------------------ | ------------------------------------------------------------- |
| **Trust First**    | Everything we build starts with trust.                        |
| **Data Integrity** | Career data must be accurate, verifiable, and tamper-evident. |
| **Empowerment**    | Give users control over their career narrative.               |
| **Privacy**        | User data is never used without explicit consent.             |
| **Innovation**     | Continuously leverage AI to improve career outcomes.          |
| **Inclusivity**    | Accessible to all professionals globally.                     |
