# Subscription Model

## Purpose

Subscription plans, tiers, and features.

## Plans

### Individual

| Plan | Price/Month | Features                              |
| ---- | ----------- | ------------------------------------- |
| Free | $0          | Passport, 10 claims                   |
| Pro  | $19         | Unlimited claims, AI resume, insights |

### Organization

| Plan       | Price/Month    | Features                          |
| ---------- | -------------- | --------------------------------- |
| Team       | $99 + $10/user | Recruiter tools, org verification |
| Enterprise | Custom         | API, SSO, custom integrations     |

## Add-Ons

| Add-on                | Price       |
| --------------------- | ----------- |
| Priority Verification | $5 / claim  |
| AI Career Coaching    | $29 / month |

## Billing Cycle

- Monthly and annual billing.
- 20% discount for annual plans.
