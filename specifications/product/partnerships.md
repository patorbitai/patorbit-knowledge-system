# Partnerships

## Purpose

Partner integration model.

## Partner Types

| Type                  | Examples                               | Integration     |
| --------------------- | -------------------------------------- | --------------- |
| ATS Partners          | Greenhouse, Lever, Workday             | API integration |
| Verification Partners | Degree verification, background checks | API             |
| Identity Partners     | Google, LinkedIn, GitHub               | OAuth           |
| AI Partners           | Claude API, embedding models           | API             |
| Channel Partners      | HR consultancies, staffing firms       | Reseller        |

## Partner Lifecycle

1. **Application**: Partner registers interest.
2. **Integration**: Technical integration completed.
3. **Launch**: Partner goes live.
4. **Growth**: Joint go-to-market.
5. **Review**: Annual partnership review.
