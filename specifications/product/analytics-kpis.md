# Analytics & KPIs

## Purpose

Success metrics and KPI framework for the platform.

## North Star Metric

**Verified Claims**: The number of claims that have been submitted, linked to evidence, and successfully verified. This captures both platform engagement and trust.

## KPI Categories

| Category         | Key KPIs                                                         |
| ---------------- | ---------------------------------------------------------------- |
| **Acquisition**  | New registrations, activation rate, time to first claim          |
| **Engagement**   | DAU/MAU, claims per user, resumes generated                      |
| **Verification** | Verification rate, time to verification, evidence-to-claim ratio |
| **Retention**    | Day 7/30/90 retention, passport update frequency                 |
| **Revenue**      | MRR, ARPU, conversion rate, churn rate                           |
| **Satisfaction** | NPS, support tickets, feature satisfaction scores                |

## Reporting Cadence

| Frequency | Report                    | Audience     |
| --------- | ------------------------- | ------------ |
| Daily     | Product metrics dashboard | Product team |
| Weekly    | Growth metrics            | Leadership   |
| Monthly   | Business review           | All          |
| Quarterly | Strategy review           | Board        |
