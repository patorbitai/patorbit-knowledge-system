# Documentation Strategy

## Purpose

Product documentation approach and standards.

## Documentation Types

| Type               | Audience       | Format               |
| ------------------ | -------------- | -------------------- |
| Product Handbook   | Internal teams | Markdown (this repo) |
| User Documentation | End users      | Help center          |
| Developer Docs     | API consumers  | Developer portal     |
| Release Notes      | All            | Blog / Changelog     |

## Principles

- **Single Source of Truth**: This repository is canonical.
- **Versioned**: Docs versioned with releases.
- **Discoverable**: Searchable across all platforms.
- **Current**: Docs updated with feature releases.
