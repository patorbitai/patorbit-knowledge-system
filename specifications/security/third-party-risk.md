# Third-Party Risk

## Purpose

Vendor risk management process.

## Vendor Risk Tiers

| Tier     | Data Access          | Review Cadence          |
| -------- | -------------------- | ----------------------- |
| Critical | Full data access     | Annual + incident-based |
| High     | Limited data         | Annual                  |
| Medium   | No data, operational | Biennial                |
| Low      | No access            | Onboarding only         |

## Assessment Process

1. **Identification**: Catalog all third-party vendors.
2. **Tiering**: Classify by data access and criticality.
3. **Assessment**: Security questionnaire, SOC 2 review.
4. **Remediation**: Address findings before go-live.
5. **Ongoing**: Continuous monitoring, annual review.
