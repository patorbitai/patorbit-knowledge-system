# Dependency Security

## Purpose

Managing security risks in third-party dependencies.

## Controls

| Control                           | Implementation             |
| --------------------------------- | -------------------------- |
| Software Bill of Materials (SBOM) | Generated with each build  |
| Dependency Scanning               | Automated scanning on PR   |
| License Compliance                | Automated license check    |
| Dependency Pinning                | Lock files committed       |
| Update Policy                     | Regular dependency updates |
