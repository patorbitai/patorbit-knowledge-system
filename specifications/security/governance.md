# Governance

## Purpose

Security governance structure, roles, and decision-making.

## Governance Structure

| Body                   | Members                          | Frequency | Responsibilities                     |
| ---------------------- | -------------------------------- | --------- | ------------------------------------ |
| Security Council       | CISO, CTO, Legal, Product Lead   | Monthly   | Strategic direction, risk acceptance |
| Security Working Group | Security team, Engineering leads | Weekly    | Operational security decisions       |
| Incident Response Team | On-call rotation                 | 24/7      | Incident handling                    |

## Roles

| Role                    | Responsibilities                           |
| ----------------------- | ------------------------------------------ |
| CISO                    | Overall security strategy, risk acceptance |
| Security Engineer       | Implementation, monitoring, response       |
| Security Champion       | Embedded in engineering teams              |
| Data Protection Officer | Privacy compliance                         |

## Decision Framework

- Risk-based: Decisions based on risk assessment.
- Transparent: All decisions documented with rationale.
- Accountable: Clear ownership for each decision.
