# Privacy

## Purpose

Privacy by Design implementation for the Patorbit platform.

## Privacy Principles

1. **Data Minimization**: Collect only necessary data.
2. **Purpose Limitation**: Use data only for stated purposes.
3. **User Control**: Users manage their own data.
4. **Transparency**: Clear data handling policies.

## User Rights

| Right         | Implementation                       |
| ------------- | ------------------------------------ |
| Access        | Self-service data export             |
| Rectification | Edit profile/passport directly       |
| Erasure       | Account deletion (with verification) |
| Portability   | Export passport in standard format   |
| Restriction   | Limit processing of certain claims   |
| Objection     | Opt out of AI analysis               |

## Regional Compliance

- GDPR (EU): Full data subject rights, DPA required.
- CCPA (California): Opt-out of data sale.
- DPDP (India): Consent framework, data localization readiness.
