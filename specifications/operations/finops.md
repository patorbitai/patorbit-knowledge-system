# FinOps

## Purpose

Cloud cost governance and optimization.

## Cost Governance

| Role             | Responsibility          |
| ---------------- | ----------------------- |
| FinOps Team      | Budgeting, optimization |
| Engineering Lead | Service cost ownership  |
| Product Manager  | Feature cost/benefit    |

## Cost Optimization

| Strategy               | Impact                 |
| ---------------------- | ---------------------- |
| **Right-Sizing**       | 10-20% savings         |
| **Spot Instances**     | 50-70% savings         |
| **Autoscaling**        | 20-40% savings         |
| **Reserved Instances** | 30-60% savings         |
| **Semantic Caching**   | 30-50% AI cost savings |

## Chargeback/Showback

- All resources are tagged by service and owner.
- Monthly cost reports are generated per service.
